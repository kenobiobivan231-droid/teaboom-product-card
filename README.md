## 📌 О проекте

В рамках тестового задания разработана верхняя часть адаптивной карточки товара **«Ананасовый улун»** в строгом соответствии с фирменным стилем и айдентикой **Teaboom.ru** (сочетание теплого медово-золотого акцента `#F5D730`, графитового темного текста `#1E2022`, чистого фона карточки и аутентичной типографики).

Верстка выполнена с нуля без использования Bootstrap и готовых шаблонов интернет-магазинов, с упором на семантику HTML5, современный SCSS/CSS3, модульный Vanilla JavaScript, высокую доступность (a11y) и безупречную адаптивность.

## 🚀 Быстрый запуск

### Вариант 1. Без сборки (мгновенно)
Просто откройте файл `index.html` в любом современном браузере (двойной клик по файлу или перетаскивание в окно браузера).  
Все стили (`css/style.css`), скрипты (`js/main.js`) и графические ассеты уже скомпилированы и готовы к работе автономно.

### Вариант 2. Локальный веб-сервер
```bash
# Установка зависимостей (Dart Sass)
npm install

# Запуск локального сервера (порт по умолчанию)
npm start
# или
npx serve .
# или Python 3
python -m http.server 8080
```
Страница будет доступна по адресу: `http://localhost:3000` (или `http://localhost:8080`).

### Сборка и компиляция стилей (SCSS → CSS)
```bash
# Разовая компиляция стилей
npm run build:css

# Режим отслеживания изменений (watch)
npm run watch:css
```

## 🎯 Реализованная функциональность

### 1. Переключение фасовок (Packaging Selector)
Реализован доступный радио-селектор фасовок со следующими параметрами по ТЗ:
* **100 г**: арт. `01306` | `349,20 ₽` → **`326,40 ₽`** (скидка `-7%`, выгода `22,80 ₽`)
* **500 г**: арт. `01307` | `1 646 ₽` → **`1 432 ₽`** (скидка `-13%`, выгода `214 ₽`)
* **1000 г**: арт. `01308` | `2 592 ₽` → **`2 064 ₽`** (скидка `-20%`, выгода `528 ₽`)
* **5000 г**: арт. `01309` | `8 710 ₽` → **`6 320 ₽`** (скидка `-27%`, выгода `2 390 ₽`)

**При переключении фасовки синхронно обновляются:**
* Актуальная цена и старая зачеркнутая цена;
* Артикул товара (SKU);
* Бейдж процента скидки (`-7%`, `-13%`, `-20%`, `-27%`);
* Сумма экономии для покупателя и расчет стоимости за 100 грамм;
* Выбранное состояние радио-кнопки (визуальная обводка, золотая плашка, фокус для клавиатуры);
* Текстовая подпись в legend селектора;
* Мобильный фиксированный бар быстрого заказа.

### 2. Кнопка «В корзину» и микроанимации
* Обычное состояние: контрастный акцентный цвет Teaboom, иконка корзины, тень;
* Состояние `:hover`: мягкий подъем кнопки (`translateY(-2px)`), увеличение тени и насыщенности цвета;
* Состояние `:active`: тактильное вдавливание;
* Состояние `:focus-visible`: контрастное кольцо фокуса для навигации с клавиатуры;
* **Интерактив при клике:**
  * Кнопка временно окрашивается в зеленый цвет со статусом «В корзине (X шт) ✓» и анимацией галочки;
  * Обновляется и анимируется бейдж-счетчик корзины в шапке сайта;
  * Появляется всплывающее уведомление (Toast) с информацией о добавленной фасовке, количестве и общей стоимости.

### 3. Галерея изображений и Zoom
* Квадратный контейнер `aspect-ratio: 1 / 1` с бейджами скидки и статусом «В наличии»;
* Интерактивные миниатюры со сменой ракурса чая;
* Интерактивный оптический зум при наведении курсора на десктопе (`transform-origin` следует за мышью);
* Полноэкранный просмотр изображения (Lightbox) по клику с закрытием по кнопке, оверлею или клавише `Escape`.

### 4. Дополнительные возможности и внимание к мелочам
* **Счетчик количества (Quantity Stepper):** кнопки `-` и `+`, блокировка минуса на `1`, поддержка ручного ввода с автоограничением от `1` до `99`;
* **Кнопка «В избранное»:** пульсирующая анимация сердечка, изменение `aria-pressed`, счетчик избранного в шапке, уведомление в Toast;
* **Кнопка «Поделиться»:** копирование ссылки на товар в буфер обмена с подтверждением в Toast;
* **Кнопка «Купить в 1 клик»:** быстрое оформление без корзины;
* **Карточки параметров заваривания:** температура `80–85 °C`, время `1–3 мин`, пропорция `2 ч. л. / 500 мл`, регион `Китай, Фуцзянь`;
* **Теги вкусового профиля:** `Тропический ананас`, `Весенняя зелень`, `Медовые ноты`, `Антиоксидант`;
* **Аккордеон информации:** раскрывающиеся вкладки «Полезные свойства и эффект» и «Доставка и оплата» с сохранением доступности (`aria-expanded`, `aria-controls`);
* **Мобильный Sticky Bar:** фиксированная нижняя панель с ценой и кнопкой «В корзину», плавно появляющаяся через `IntersectionObserver`, когда основная кнопка покупки скрывается из области видимости при скролле.

Верстка протестирована и обеспечивает идеальное отображение на всех контрольных контрольных разрешениях:

| Устройство | Разрешение | Особенности адаптации |
|---|---|---|
| **Desktop** | `1440px` (и 1920px+) | Двухколоночный просторный грид, 4 колонки фасовок в ряд, увеличение фото при наведении, плавающие бейджи |
| **Tablet** | `768px` (и 1024px) | Оптимизированный двухколоночный грид с сеткой фасовок 2×2, сохранение читаемости всех цен и артикулов без горизонтального скролла |
| **Mobile** | `375px` (и до 320px) | Одноколоночный вертикальный флоу, удобные touch-target элементы (≥44px), компактный header, нижний sticky bar для максимальной конверсии |

## 🛠 Технические требования и стандарты

* **HTML5:**
  * Семантические теги: `<header>`, `<main>`, `<article>`, `<nav>`, `<figure>`, `<picture>`, `<fieldset>`, `<legend>`, `<aside>`, `<time>`, `<button>`;
  * Микроразметка **Schema.org** (`itemscope itemtype="https://schema.org/Product"`, `BreadcrumbList`, `Offer`);
  * Стандарты доступности **WAI-ARIA 1.2** (`role="radiogroup"`, `aria-live="polite"`, `aria-expanded`, `aria-pressed`, `aria-label`).
* **CSS / SCSS:**
  * Методология БЭМ (Блок-Элемент-Модификатор);
  * Архитектура Dart Sass 3.0 с использованием `@use`;
  * CSS Custom Properties (дизайн-токены цветов, радиусов, теней, переходов);
  * Fluid-типографика через `clamp()`;
  * Flexbox и CSS Grid;
  * Учет `prefers-reduced-motion` для пользователей с чувствительностью к анимациям.
* **JavaScript:**
  * Чистый Vanilla JS (ES6+), отсутствие jQuery, React или сторонних библиотек;
  * Строгий режим `'use strict'`;
  * Модульная организация с кешированием элементов DOM и централизованным объектом состояния;
  * Нативная работа со событиями (`change`, `click`, `mousemove`, `keydown`, `IntersectionObserver`).
* **Графика:**
  * Оригинальные ассеты высокого разрешения Teaboom.ru;
  * Четкие векторные inline SVG иконки без сторонних иконочных шрифтов.
